  <section id="conceitos">
    <h2 class="section-title">2. Cinco conceitos que você precisa entender antes de clicar em qualquer coisa</h2>
    <p class="lead">Você não precisa saber programação. Mas precisa reconhecer estas cinco peças para não montar o fluxo “de trás para frente”.</p>
    <div class="grid-3">
      <div class="card"><span class="pill blue">Gatilho</span><h3>O que inicia algo</h3><p>No seu caso, a venda aprovada precisa resultar na aplicação de uma tag. Essa tag inicia o fluxo.</p></div>
      <div class="card"><span class="pill wine">Tag</span><h3>Uma etiqueta no contato</h3><p>Ex.: <code>#COMPRA-APROVADA</code>. Tags também servem para condições, como “já comprou o upsell?”.</p></div>
      <div class="card"><span class="pill gold">Template HSM</span><h3>Mensagem pré-aprovada</h3><p>É a mensagem usada para iniciar uma conversa no WhatsApp quando não existe uma janela de atendimento aberta.</p></div>
      <div class="card"><span class="pill green">Janela de 24 h</span><h3>Período de mensagens livres</h3><p>A janela de atendimento abre quando o cliente envia uma mensagem. Por isso, prefira um botão de resposta rápida que faça o comprador efetivamente responder.</p></div>
      <div class="card"><span class="pill blue">Webhook</span><h3>Um aviso automático entre sistemas</h3><p>O checkout “avisa” que a compra foi aprovada. Uma integração recebe esse aviso e manda a informação para o UnniChat.</p></div>
      <div class="card"><span class="pill wine">Condicional</span><h3>Uma pergunta com dois caminhos</h3><p>“O contato possui a tag <code>UPSELL-COMPRA-APROVADA</code>?” Sim: não ofertar. Não: ofertar.</p></div>
    </div>
    <div class="callout warn"><b>Regra importante do WhatsApp:</b> entregar um template não é o mesmo que o cliente responder. Para usar mensagens livres depois, o cliente precisa enviar uma mensagem/interação que abra a janela de atendimento. Por isso, no template inicial, use um botão de <b>resposta rápida</b> (“Ver detalhes”), não apenas um botão de URL, se o objetivo é continuar o fluxo com mensagens livres.</div>
  </section>
